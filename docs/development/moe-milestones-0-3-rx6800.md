`llama-moe-corpus` evaluates up to18 cases in one initialized model/context per process. It records complete raw logits and token IDs for every physical prefill chunk and decoded token, refuses nonfinite or all-zero vectors, and supports explicit teacher-forced decode IDs. Before each case it synchronizes and clears memory data; scheduler pools deliberately persist to test consecutive requests. Full40-layer callback routing is optional and measured separately because callbacks synchronize the scheduler and disable pool admission. `MOE_REPLAY_PROFILE` uses the case index as rep to join phases. Raw guards and I/O are outside the decode/synchronize timing interval; this timing excludes sampling and is not application TTFT.

Resource guards: one GPU inference process at a time, MemoryMax24G, SwapMax2G, at least6GiB MemAvailable,600s timeout. The user GPU clock/voltage/power profile is preserved. Each process records loaded DLL hashes, actual RADV device, driver/library identity, RSS/PSS, affinity, cgroup/swap, VRAM/GTT and failure artifacts. Raw passing cells do not erase historical failures or justify performance ranking of failed cells.
